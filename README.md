# web-fliqlo ⏰

An authentic, single-file HTML web replica of the iconic **Fliqlo Flip Clock screensaver**, powered by local PC time.

![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat-square&logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat-square&logo=javascript&logoColor=black)

## ✨ Features
- **Authentic Fliqlo Design**: Dark matte flip cards, side hinge cutouts, center cut line, and crisp bold typography.
- **Local PC Time Sync**: Reads directly from native browser time with 60fps 3D flip card fold animations.
- **Secret 5-Click Controls (Top-Left)**:
  - Invisible top-left click hotspot (click 5 times in top-left to reveal controls).
  - 5-second hover-away auto-disappear timer for a clean full-screen screensaver view.
- **Customization Options**:
  - 12-Hour / 24-Hour mode format toggle.
  - Show / Hide AM/PM badge.
  - Optional Seconds card unit.
  - Clock scale slider (50% to 150%).
  - Fullscreen mode toggle (`F` key shortcut).

## 🚀 Quick Start
Simply open `index.html` in any web browser! No dependencies or build steps required.
